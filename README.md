# منيو بيتزا فريش الإلكتروني الذكي | Pizza Fresh Menu 🍕✨

تطبيق ويب فائق السرعة، أنيق ومستقل بذاته (Single-File Standalone)، مصمم خصيصاً لمطعم **"بيتزا فريش" (Pizza Fresh)** في الإسكندرية.

---

## 🌟 مميزات المنيو:
1. **واجهة Icon App 5 نجوم:**
   - كارت المطعم الرئيسي، حالة المحل المباشرة، وأزرار الاتصال والواتساب وواي فاي الصالة ومواعيد العمل.
   - شريط الأقسام الدائري الأيقوني مع مؤشر دهبي متحرك.
2. **صور أطباق حية ومتحركة:**
   - صور حقيقية ومفروزة بدقة 100% لكل صنف (سجق، بسطرمة، جمبري، نوتيلا، كيري، نجرسكو...).
   - تأثير تصاعد البخار الحي وحركة الكاميرا السينمائية الهادئة.
3. **استوديو تخصيص الأصناف والأحجام:**
   - اختيار الحجم أو الإضافة (`عادي`، `جبنة زيادة`، `كيري`، `كيري وجبنة زيادة`، أو أحجام الطواجن والفطير).
   - قائمة صوصات وإضافات اختيارية تتفاعل لحظياً مع السعر.
4. **خدمة توصيل الإسكندرية (49 منطقة):**
   - حساب مصاريف التوصيل أوتوماتيكياً لكل منطقة (سكينة، زون فريش، سموحة، ميامي، العوايد...).
5. **استوديو باركود QR للطباعة:**
   - توليد باركود QR عالي الدقة بشعار المحل جاهز للطباعة على الكراتين والترابيزات (تحميل PNG بضغطة زر).
6. **طلب فوري بالواتساب:**
   - إرسال تفاصيل الفاتورة كاملة بالاسم والعنوان والأصناف إلى الرقم المعتمد **`01211319400`**.

## 🚀 كيفية نشر المنيو أونلاين مجاناً 100% في ثوانٍ:

### الطريقة 1: Netlify Drop (في 10 ثواني - بدون أي تسجيل أو برمجة) ⭐
1. افتح موقع: [app.netlify.com/drop](https://app.netlify.com/drop)
2. اسحب فولدر `pizza-fresh` وأفلته في المربع الأزرق في الصفحة.
3. مبروك! ستحصل فوراً على رابط إنترنت دائم وسريع مجاناً مدى الحياة (يمكنك نسخه ومشاركته لزبائنك).

### الطريقة 2: GitHub Pages (رسمي ودائم)
1. في مستودع GitHub الخاص بك، اذهب إلى: **Settings -> Pages**.
2. اختر الفرع `main` أو `master` ومسار `/root`.
3. اضغط **Save**، وسيكون الرابط متاحاً على:
   `https://<username>.github.io/<repo>/pizza-fresh/`

### الطريقة 3: Vercel
1. افتح [vercel.com](https://vercel.com) وسجّل بحساب GitHub.
2. اختر المستودع واضغط **Deploy** ليحصل المنيو على نطاق فخم وسريع مثل `pizzafresh.vercel.app`.
